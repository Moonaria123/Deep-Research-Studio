# Media provenance

- `hero.png` is an original illustration generated with an image model. The final prompt is preserved in `hero-prompt.txt`.
- `demo-60s.mp4` records real browser interactions with the English Gen1 Web interface in the preset-data preview build. Only the application viewport is captured; the video has no audio.
- `demo-15s.gif` edits selected moments from that recording into a short tour.
- `screenshots/` contains original browser captures of the same English preview, organised by feature. They have not been retouched into simulated product screens.

The preview uses fixed, sanitised research examples with no provider credentials or live model or search calls. Research playback shows preset results rather than a newly generated report. The recording and screenshots are checked for credentials, private information, unrelated applications, and failed interface states before publication.
