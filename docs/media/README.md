# Media provenance

- `hero.png` is an original illustration generated with an image model. The final prompt is preserved in `hero-prompt.txt`.
- `demo-60s.mp4` records the actual Gen1 Web application and local API, using public research examples. Only the application viewport is captured; the video has no audio.
- `demo-15s.gif` edits selected moments from that recording into a short tour.
- `screenshots/` contains original application screenshots organised by feature. They have not been retouched into simulated product screens.

The recording and screenshots were reviewed for credentials, private information, unrelated applications, and failed interface states before publication. The hosted static Demo is a separate preview build with preset data.
