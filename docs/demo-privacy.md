# Hosted Demo: behaviour and privacy

[简体中文](#简体中文)

The hosted Demo at <https://moonaria123.github.io/Deep-Research-Studio/> is a static interface preview.

- It contains fixed, sanitised examples for the four research modes and the main application pages.
- It has no model or search-provider credentials and cannot invoke a model, search the Web, upload a document, or save configuration.
- Research playback and regeneration use predetermined events and results.
- Interface changes stay in memory and reset when the page reloads. The Demo does not write application data to cookies, local storage, session storage, or IndexedDB.
- GitHub Pages hosts the static files. GitHub states that it logs visitors' IP addresses for security purposes; this is outside the application's data handling. See [What is GitHub Pages?](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection).

Do not enter personal, confidential, or proprietary material into the Demo. Use a local installation for real research.

## 简体中文

<https://moonaria123.github.io/Deep-Research-Studio/> 上的线上 Demo 是静态界面预览。

- Demo 使用固定、脱敏的四种研究模式和主要页面样例。
- Demo 没有模型或搜索 Provider 凭据，不能调用模型、搜索网页、上传文档或保存配置。
- 研究回放与重新出具使用预设事件和结果。
- 界面变化只保留在内存中，刷新后重置。Demo 不会把应用数据写入 Cookie、localStorage、sessionStorage 或 IndexedDB。
- 静态文件由 GitHub Pages 托管。GitHub 说明其会出于安全目的记录访客 IP；这不属于应用自身的数据处理。参见 [GitHub Pages 数据收集说明](https://docs.github.com/zh/pages/getting-started-with-github-pages/what-is-github-pages#data-collection)。

请勿在 Demo 中输入个人、机密或专有资料。真实研究请使用本地安装。
